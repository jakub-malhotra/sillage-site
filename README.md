# sillage

[live site](https://sillage-flax-kappa.vercel.app/)

a web app that picks a fragrance from your collection based on the day's weather. it fetches real-time temperature and humidity, then uses a serverless ai endpoint to match the climate against the scent profiles saved in your local storage. the ui dynamically updates its background gradients to reflect the recommended fragrance family.

### stack
react, typescript, vite, tailwind, tanstack router, vercel serverless functions.
